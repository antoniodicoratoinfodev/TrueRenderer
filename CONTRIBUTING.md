# Collaborazione

TrueRenderer usa una licenza proprietaria: il repository pubblico non concede
una licenza generale per riutilizzare o distribuire il codice. Vedere `LICENSE`.

Le segnalazioni riproducibili sono benvenute. Prima di inviare codice o asset,
concordare con il titolare i termini della contribuzione e i diritti necessari.
Non inviare fotografie, profili o codice di terzi senza i relativi permessi.

Per le attività autorizzate, seguire `AGENTS.md`, `PLAN.md` e gli ADR. I test e
le librerie di prova sono separati dai dati durevoli sotto `var/`.
